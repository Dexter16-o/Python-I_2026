# Python-I 2026

Daily Python programs completed in class for **Python-I**. This repository contains the scripts and Jupyter notebooks written during college lectures, along with their supporting files.

## Repository structure

| Folder | Contents |
| --- | --- |
| `T1/Programs/` | Test 1 in-class Python programs and practice work, with related Jupyter notebooks in `jupyter files/`. |
| `T2/Programs/` | Test 2 in-class programs, with matching notebooks in `Jupyter_Programs/`. |
| `T3/Programs/` | In-class lecture programs grouped by lecture (`Lec_1_2`, `Lec_3_4`, and `Lec_5_6`). |
| `T3/Jupyter Programs/` | Lecture notebooks and text files used by file handling programs. |
| `T1/`, `T2/`, `T3/` | Supporting lecture notes, practice material, and reference documents. |

## How to run the programs

Run a `.py` file with Python 3 from a terminal or open it in a Python editor. Jupyter notebooks (`.ipynb`) can be opened in Jupyter Notebook, JupyterLab, or a compatible editor. Keep each program alongside its referenced text files and other supporting files so file operations can find them. Some programs expect input from the user when they run.

## Note

The repository records the daily programs completed during college lectures. File names and topics follow the class material and are organized by test and lecture.
